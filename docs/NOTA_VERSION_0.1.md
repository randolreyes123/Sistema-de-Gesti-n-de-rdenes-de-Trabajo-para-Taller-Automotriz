# Nota técnica de versión 0.1

## Identificación

**Versión:** 0.1 - Línea base académica

**Sistema:** Sistema de Gestión de Órdenes de Trabajo para Taller Automotriz

## Contenido de la versión

La versión 0.1 reúne los artefactos técnicos elaborados durante la asignatura:

- Definición del problema, objetivo, alcance y usuarios.
- Requisitos funcionales y no funcionales.
- Historias de usuario y criterios de aceptación.
- Modelos UML.
- Arquitectura por capas.
- Organización frontend/backend.
- Diez Issues para seguimiento técnico.
- Tablero Kanban en GitHub Projects.
- Registro de cambios y documentación principal del repositorio.

## Cambios controlados

Durante esta versión se controlaron principalmente cambios de análisis, diseño y organización del proyecto. Se consolidaron requisitos, se definieron modelos y arquitectura, se organizaron las tareas técnicas y se actualizó la documentación del repositorio.

## Aspectos pendientes

- Implementar los módulos funcionales priorizados.
- Completar las validaciones de datos.
- Realizar pruebas funcionales e integración.
- Mantener trazabilidad entre Issues, commits y pruebas.
- Fortalecer el historial de control de versiones a medida que avance la implementación.

## Próximo paso técnico

El siguiente hito debe ser iniciar la implementación del módulo de órdenes de trabajo, por ser el núcleo del sistema, y relacionar cada cambio realizado con el Issue correspondiente, un commit descriptivo y una prueba verificable.

## Alcance de esta versión

Esta versión no representa un producto listo para producción. Corresponde a una línea base académica de análisis, diseño, arquitectura, documentación y planificación técnica.
