# Sistema de Gestión de Órdenes de Trabajo para Taller Automotriz

Proyecto académico de Ingeniería de Software orientado a organizar y controlar las órdenes de trabajo de un taller automotriz.

## Objetivo

Desarrollar un sistema que permita registrar clientes y vehículos, crear órdenes de trabajo, documentar diagnósticos, registrar servicios y repuestos, calcular costos y consultar el historial de mantenimiento de cada vehículo.

## Funciones principales

- Registro de clientes.
- Registro de vehículos.
- Creación y seguimiento de órdenes de trabajo.
- Registro de diagnósticos.
- Registro de repuestos y costos.
- Consulta del historial de servicios.

## Metodología

El proyecto será organizado con un enfoque ágil basado en Kanban utilizando GitHub Projects. El tablero se dividirá en los estados: Backlog, Por hacer, En progreso, En revisión y Finalizado.
